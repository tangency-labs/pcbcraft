# Toolbar artwork

These unchanged SVG masters come from the independent PCBcraft Next prototype,
revision `568cd495397a91563e563e7163efb226d84fa83a`, at
https://github.com/travle1/pcbcraft-next. Original artwork is copyright 2026
Travis Lowe and contributors, MIT OR Apache-2.0. The five family masters are
copyright 2026 SolidCraft contributors, MIT OR Apache-2.0; their original
SolidCraft source pins are retained in `provenance.json` along with all source
paths and SHA-256 hashes.

`ribbon_icons.rs` resolves source palette roles to chrome tokens at runtime while
preserving mask paints. It decodes embedded SVGs only. Both projects' MIT and
Apache license texts and SolidCraft's NOTICE are retained here. That upstream
NOTICE describes SolidCraft as a whole; only the five registered SVG assets are
reused here. The full source and adaptation record is in the repository's
ATTRIBUTION.md. No KiCad artwork or implementation is included in this port.
