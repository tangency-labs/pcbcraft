# Layer shortcut investigation: source boundary

Date: November 7, 2026.
Task branch: travle1/board-outline, following d34b1db.

While checking KiCad's published keyboard shortcuts, a web search unexpectedly
returned a result from docs.kicad.org/doxygen/gerbview__actions_8cpp_source.html,
including an implementation-derived excerpt. The page was not opened. Reading
stopped when the returned result was recognized as an excluded source. No excerpt
is reproduced here; no shortcut implementation had been written when the result
was encountered.

The affected layer-shortcut investigation was paused under the repository's source
rule pending the user's disposition below. Existing color and rendering code
predates this search. Non-copper display colors and ribbon color swatches can be
implemented independently using the current PCBcraft model, its existing chrome
and approved visual references; they do not require that result.

The user was informed in commentary. This record does not clear or replace any
previous source-exposure record, including the separate PCBcraft Next record.

After an explanation of the incident and rule, the user explicitly authorized:
"Continue using the manual only". Shortcut implementation may resume using the
published user manual as the sole KiCad reference. The returned implementation
result remains excluded: it must not be reopened, quoted, copied or used as an
implementation reference. This is a bounded user disposition for this incident,
not a clean-room certification or a resolution of any older exposure record.
